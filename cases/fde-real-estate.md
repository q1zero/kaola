# REAL ESTATE LEADS

房地产直播线索：从留资，到销售接手。

作者：戚逸霖

状态：实际交付 · 已投入使用

角色：独立搭建 · 部署与培训

这是 WORK_AUTO 的业务交付案例。从房地产新媒体运营现场出发，解决双平台线索进入后需要人工整理、分配与通知的问题，推动线索从“平台里的一条记录”进入销售协同。

## 业务流程

1. 双平台归集
2. 规则分配
3. 文档回写
4. 销售通知

## 业务现场与瓶颈

地产多项目同时开展直播获客，线索来自抖音和视频号。运营需要在平台、表格和沟通群之间反复切换，完成归集、分配、登记和通知。真正需要解决的是线索进入后如何顺畅交给销售，以及多项目并行时如何保持处理口径一致。

## 需求拆解与流程设计

围绕“线索从哪里来、归属哪个项目、按什么规则分配、登记到哪里、由谁接收”拆解流程，把原本依赖运营逐步操作的工作连接成连续链路。需求重点落在归属清晰、分配明确和处理记录可追溯，便于运营与销售协同。

## 系统链路与技术实现

以 Python / FastAPI 组织双平台采集与处理任务，按项目隔离配置和数据；通过规则路由完成线索分配，连接腾讯文档回写与群通知。平台数据进入、业务记录沉淀和销售接收共同组成应用层交付范围。

## 我的职责与落地过程

独立完成需求拆解、系统搭建、平台联调，以及公司服务器上的应用层私有化部署。交付后开展内部培训，让使用者理解数据入口、分配规则和日常操作方式；再根据实际使用反馈持续迭代，使工具进入日常工作流程。

## 交付价值与业务衔接

交付内容覆盖线索采集、规则分配、文档登记和销售通知，减少运营在不同工具间搬运数据。业务人员可以围绕项目归属和分配记录接手工作，把更多时间放在沟通、跟进与处理需要人工判断的事项上。

## 使用结果与指标口径

已服务 3 个外部甲方项目，接入抖音和视频号。重复操作时间减少约 70% 为个人日常使用体验估算，非严格基准测试。该项目的价值主要体现为运营流程提效；当前采用规则自动化，不包含 LLM / Agent 生产接入。
